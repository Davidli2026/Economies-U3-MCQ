# Edexcel IAL Economics U3 · Business Behaviour Quiz

A static practice quiz containing the first six Section A questions from each included paper, labelled by exam date and original question number (for example, `2020.01 Q1`). English answer choices are paired with Chinese translations, and submitted answers include bilingual explanations. Learners can choose one, six or ten questions, or “一战到底” (all remaining unanswered questions), continue with unseen questions, reshuffle the full bank, and keep a browser-local mistake book. Each completed session shows its total time and average time per question. It runs in a browser and needs no server or build step. The supplied question papers and mark schemes were used to transcribe the questions and verify the answer keys. Figures are included as separate image assets.

The current bank includes papers from January and October 2020, January, May and October 2021–2025. The October 2025 entries use the supplied international paper.

The file names identify the second paper as `2020.10`; its cover page prints “Monday 18 May 2020,” while its mark scheme is headed October 2020. The quiz uses `2020.10` to match the supplied file names and mark scheme.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Add these files to a GitHub repository.
2. In the repository settings, open **Pages**.
3. Choose deployment from the `main` branch and the root (`/`) folder.
4. Save; GitHub Pages will provide the site link.
